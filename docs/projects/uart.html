UART Serial Core

VerilogIcarus VerilogSerial Protocol
GitHub

Overview

"Learning and building UART." UART is the two-wire device-to-device protocol behind most embedded systems — asynchronous serial communication with no shared clock and a configurable speed. This project covers the concepts and implements the transmitter side with a baud-rate generator.

UART Fundamentals

  • TX / RX two-wire signalling
  • Configurable baud rates: 9600, 19200, 38400, …
  • Packet structure: start bit (high→low edge), data frame (5–8 bits, LSB first), optional parity, stop bit(s)

Implementation

  • src/baud_gen.v — baud-rate generator
  • src/uart_tx.v — UART transmitter
  • tb/baud_gen_tb.v, tb/uart_tx_tb.v — testbenches
  • Makefile-driven build

Transmission Flow

  1. Parallel data received from the data bus
  2. Start, parity, and stop bits added to the frame
  3. Full packet transmitted serially at the configured baud rate
  4. Receiver samples the line at the same rate, discards framing bits, converts serial back to parallel
