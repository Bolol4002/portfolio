GitHub

Overview

"My first attempt in RTL to GDS." A compact 4-bit accumulator in Verilog, functionally verified with a testbench, then taken through a complete open-source physical design flow — from RTL through synthesis, floor-planning, placement, routing, and LVS-clean layout.

Design

  • clk — clock input
  • rst — reset input
  • en — accumulate enable
  • data_in[3:0] — 4-bit input data
  • acc[3:0] — 4-bit accumulated output

Behaviour: on reset the accumulator clears to 0000; on each rising clock edge with en high, acc <= acc + data_in.

Physical Design Flow

  • OpenLane-style config.json driving the full flow
  • pin_order.cfg pin-ordering configuration
  • Implemented layout plus LVS (Layout vs. Schematic) verification result
  • Simulation waveform generated as img/waveforms.png

Verification

The testbench drives reset, enable and input sequences to validate correct accumulation behaviour and dumps a accumulator.vcd waveform.

iverilog -o accumulator_tb accumulator.v accumulator_tb.v vvp accumulator_tb gtkwave accumulator.vcd

Result: functional simulation plus a full PD run producing layout and LVS-clean outcomes.
