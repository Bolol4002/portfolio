Wishbone Master / Slave

VerilogiverilogBus Protocol
GitHub

Overview

An educational implementation of the Wishbone bus protocol — the open-source hardware bus used in FPGA/ASIC designs and open-source IP cores. Includes a Wishbone Master, a Wishbone Slave with 256×8-bit internal memory, and a testbench, simulated with Icarus Verilog.

Wishbone Master

Initiates bus transactions: waits for an external start pulse, then drives cyc, stb, we, adr, dat_o until the slave acknowledges with ack. De-asserts cyc/stb and clears busy on acknowledgement.

Wishbone Slave

  • 256 × 8-bit internal memory
  • Responds when cyc && stb: writes dat_o into memory[adr] when we=1, reads onto dat_i when we=0
  • Asserts ack on the clock edge

Bus Cycles & Testbench

  • Write cycle: master asserts cyc/stb/we with address + data → slave writes and acks
  • Read cycle: master asserts cyc/stb with address → slave drives data and acks
  • Testbench drives write/read transactions (addr 0x10 ← 0xAA, addr 0x20 ← 0x55), verifies, prints per-cycle log, dumps wishbone.vcd
