VLSI PD & Automation Lab

PythonVerilogEDA Algorithms
GitHub

Overview

Lab codes for the VLSI Physical Design and Automation course at KL University, Hyderabad — a dual-track collection of EDA-algorithm implementations in Python and RTL lab experiments in Verilog.

Contents

  • PDA/ — physical design automation algorithms in Python: BFS, DFS, Dijkstra, Kruskal, Prim, Kernighan–Lin partitioning, simulated annealing, course-outcome notes
  • SDEC/ — 10 RTL lab experiments (Exp01.v … Exp10.sv) with matching testbenches and a TCL script to run all simulations
  • testing_and_verification/ — VLSI testing study notes
  • OOPS/ — Java OOP lab (13 experiments)

Purpose

Hands-on grounding in the algorithmic core of physical design — graph search, routing, partitioning, and optimization — paired with practical RTL verification experiments.
