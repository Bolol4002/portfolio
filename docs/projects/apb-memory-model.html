AMBA APB Memory Model

SystemVerilogSVARandom TestingScoreboard
GitHub

Overview

An APB (Advanced Peripheral Bus) memory design plus a student-level verification environment combining three industry-style techniques: directed tests, assertions (protocol checking), and constrained random generation with self-checking.

DUT Behaviour

  • 8-bit memory with 128 valid locations (0–127)
  • Reset clears memory and outputs
  • load reads image_i.hex via $readmemh; fetch dumps via $writememh
  • Write when psel && penable && pwrite; read when psel && penable && !pwrite
  • pslverr asserted for invalid addresses (paddr ≥ 128)

Verification Architecture

  • Transaction layer — apb_write() / apb_read() implement 2-phase setup → access transfers
  • Directed tests — normal + invalid-address paths
  • SVA assertions — penable_implies_psel, ctrl_stable_in_access, pready_only_when_enable
  • Random traffic generator — 50 random ops, self-checked against a ref_mem[0:127] scoreboard
  • PASS / FAIL summary reporting
