Valid/Ready Pipeline Stage

SystemVerilogcocotbVerilatorHandshake
GitHub

Overview

A single pipeline stage implementing the classic valid/ready flow-control protocol used across hardware streaming interfaces:

  • valid (producer) — "I have valid data on data"
  • ready (consumer) — "I can accept data now"
  • A transfer happens when both are asserted on the same clock edge

The stage holds one data word and supports bubble-through: when its data is accepted downstream it can accept new input in the same cycle.

DUT Behaviour

  • ready_in = ~valid_reg || ready_out — accepts when empty OR when downstream is accepting
  • valid_out = valid_reg, data_out = data_reg
  • Reset clears the stage
  • Capture and forwarding can happen in the same cycle to avoid deadlocks

Structure & Verification

  • src/valid_ready_single.sv — parameterizable-width (WIDTH=8) DUT
  • tb/test_valid_ready.py — cocotb testbench verifying functionality and back-pressure behaviour
  • Runs with Verilator via Makefile; pinned cocotb dependency
