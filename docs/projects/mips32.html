Overview

Study notes and roadmap for building a subset of the MIPS32 ISA — architecture fundamentals, instruction encoding, and the classic 5-stage pipeline. Implementation planning in progress.

MIPS32 Basics

  • 32 general-purpose registers (R0–R31), 32-bit PC
  • No flag register; limited addressing modes
  • Only load / store instructions access memory
  • Word-addressable 32-bit memory space

Instruction Subset

  • Load / store: LW R2,124(R8), SW R5,-10(R25)
  • Arithmetic / logic: ADD, SUB, AND, OR, MUL, SLT
  • Immediates: addi, subi, slti and friends
  • R / I / J-type encoding formats with decoded opcodes (add 000000 … hlt 111111; lw 001000 … beqz 001110)

5-Stage Pipeline Study

IF (fetch) → ID (decode / register fetch) → EX (ALU / effective address) → MEM (memory access / branch completion) → WB (write back). Instruction fetch updates the NPC (NPC ← PC+1) and decodes in parallel with register reads.
