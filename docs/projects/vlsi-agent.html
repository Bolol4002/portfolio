Overview

An LLM-powered Verilog simulation agent that automatically generates testbenches, compiles, runs simulations, and fixes failing test cases. Paste a Verilog module — the agent handles verification end to end.

Pipeline

  1. Generates a testbench with an LLM (BluesMinds API / GLM-5.2)
  2. Compiles with Icarus Verilog (iverilog)
  3. Runs the simulation (vvp)
  4. Analyzes PASS / FAIL results
  5. Auto-fixes compile or test failures via LLM (up to 3 retries)
  6. Renders waveforms (VCD) and an ideal-values table
  7. Falls back to an exhaustive built-in testbench if all LLM attempts fail

Architecture

Browser (static/index.html) │ POST /api/simulate { verilog_code } ▼ FastAPI (server.py :8000) ├── LLM (BluesMinds API) generate_testbench / analyze_failure / build_ideal_values ├── Icarus Verilog iverilog → vvp → wave.vcd + stdout └── Response logs, waveform_data, test_summary, ideal_values /api/simulate POST run simulation pipeline /api/waveform/{id} GET download raw VCD

Scope & Status

Currently supports combinational logic (gates, ALUs, muxes, decoders) with plans for sequential designs. Backend-driven verification reproduces the classic write-RTL / auto-generate-tests / iterate-fixes flow in seconds instead of hours.
