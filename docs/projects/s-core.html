Overview

"My nth attempt in building a CPU." A single-cycle RISC-V CPU implemented in SystemVerilog, built incrementally module by module. Every module is independently verified using cocotb (Python testbenches) and the full CPU targets FPGA synthesis on the Xilinx Artix-7 Basys 3 board.

Implemented Modules

  • ALU — 32-bit, ADD / SUB / AND / OR with zero flag
  • Register File — 32×32-bit, synchronous write, asynchronous read, x0 hardwired to zero
  • Program Counter — 32-bit PC with synchronous update and reset
  • PC+4 Adder — combinational sequential-instruction fetch
  • Instruction Memory — ROM loaded via $readmemh
  • Instruction Decoder — extracts opcode, rd, funct3, rs1, rs2, funct7
  • ALU Control — decodes R-type funct fields into ALU ops
  • Control Unit — reg_write, alu_src, mem signals, branch, jump
  • CPU Top — single-cycle datapath integration
  • FPGA Top — clock divider (100 MHz → ~1.5 Hz) driving 16 LEDs

Microarchitecture

Classic single-cycle datapath: PC → Instruction Memory → Instruction Decoder → (Control Unit, ALU Control) → Register File → ALU → writeback. Currently supporting R-type instructions (ADD, SUB, AND, OR); a pipeline, I-type instructions, branches and jumps are planned.

Verification

  • Every module has a dedicated cocotb testbench under tb/<module>/
  • Tests run with make; Icarus Verilog backend
  • 9 of 9 core modules implemented and tested

FPGA Flow

  • Target: Xilinx Artix-7 (xc7a35tcpg236-1, Basys 3)
  • Clock: 10 ns (100 MHz) with divider for LED visualization
  • Automated build via Vivado batch script (create_project.tcl)
