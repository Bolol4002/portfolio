Adaptive RTL Control Unit

VerilogSystemVerilogVivadoPower-Aware Design
GitHub

Overview

Traditional RTL uses fixed control logic that never adapts — wasting power or leaving performance on the table as workloads change. This project builds an adaptive control unit at the RTL level that dynamically switches between two strategies, proving that control-plane decisions significantly affect power and performance without modifying the datapath or underlying technology.

Design Concept

  • Power-Efficient Control Unit — minimizes switching activity, conditional decoding, gated logic
  • High-Performance Control Unit — parallel decoding, precomputed control signals, minimal critical path
  • Adaptive Control Wrapper — selects between the two units via a mode signal at runtime

Design Flow

  • Implement baseline control logic for instruction decoding
  • Develop two RTL variants (low-power, high-performance)
  • Integrate both into an adaptive control module
  • Simulate functional correctness
  • Synthesize with Xilinx Vivado
  • Analyze and compare power, resource utilization, timing

Evaluation Metrics

  • Dynamic power (switching activity / energy)
  • LUT utilization & flip-flop count
  • Critical-path delay (max frequency) & timing slack
