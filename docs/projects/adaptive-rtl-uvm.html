UVM Verification · Adaptive Control Unit

SystemVerilogUVMVerilatorGTKWave
GitHub

Overview

UVM-style verification environment for an adaptive control unit that dynamically switches between low-power (mode=0) and high-performance (mode=1) control strategies based on a runtime config signal. Verification completed with all 14 test cases passing.

Hierarchy

top_adaptive_control └── adaptive_control_unit ├── low_power_control_unit (mode=0) └── high_perf_control_unit (mode=1)

Interface

  • Inputs: clk_i, rst_n_i, opcode_i[3], valid_i, mode_i
  • Outputs: reg_write_o, mem_read_o, mem_write_o, alu_src_o, alu_op_o[3], branch_o, jump_o, plus LED mode indicators
  • Opcodes: NOP, ADD, SUB, AND, OR (3'b000–3'b100)

Verification Environment

  • UVM-style driver / monitor / scoreboard
  • Three test phases: low-power mode (all 5 opcodes), high-performance mode, and dynamic mode switching
  • Build & simulation via Verilator + GTKWave (make sim / make run / make wave / make comp)

Results

Test suite run to completion Total tests : 14 Passed : 14 Failed : 0
