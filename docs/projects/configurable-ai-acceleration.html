Configurable AI Acceleration Extension

VerilogPicoRV32Vivado 2025.2Artix-7 XC7A35TRISC-V
GitHub

Overview

Research project to design, integrate, and evaluate a configurable MAC-based AI accelerator with a PicoRV32 RISC-V core on the Digilent Basys 3 FPGA. The accelerator is driven by custom RISC-V instructions and quantified across multiple accelerator configurations and benchmark workloads.

Embedded scalar cores execute data-parallel AI workloads (matrix multiply, convolution, FIR, image filters) as long load / multiply / add sequences — giving poor throughput and energy efficiency. Existing accelerators are typically fixed-configuration and hard to drop into open-source cores. This project closes that gap.

Key Features

  • Parameterizable MAC-array engine — 2 / 4 / 8 MAC units
  • Configurable operand widths: INT8 / INT16 / INT32
  • Scratchpad memory + controller
  • Custom instructions: MATMUL, CONV, MAC, DOT, LOAD_TILE, STORE_TILE, WAIT
  • Speedup / area / power trade-off evaluation on real FPGA fabric

Architecture

The baseline is a PicoRV32 RV32I core brought up on the Basys 3 (CPU + instruction memory in block RAM, debug LEDs showing PC activity). The PCPI (Pico Co-Processor Interface) ports are wired out of the top module, ready for the accelerator to attach as a co-processor.

Evaluations compare the scalar baseline against accelerator configurations across benchmark workloads for execution cycles, speedup, area and energy.

Status & Roadmap

  • Phase 0–1 — done: problem definition + literature review (RedMulE, SCAIE-V, analog AI hardware review, CIDRE) with per-paper summaries and research-gap analysis
  • Phase 2 — done: baseline PicoRV32 running on the Basys 3; PCPI ports exposed
  • Phase 3+ — planned: benchmarks, accelerator RTL, ISA extension, verification (SystemVerilog / cocotb, differential HW-vs-SW), FPGA implementation, design-space exploration, final evaluation and paper

12-phase research roadmap with a published review-1 report and presentation under report_and_ppt/.

Tools & Target

  • Board: Digilent Basys 3 — Xilinx Artix-7 XC7A35T
  • Synthesis / implementation: Xilinx Vivado 2025.2
  • Verification (planned): SystemVerilog / cocotb, iverilog or ModelSim
  • Firmware: RISC-V GCC toolchain · Baseline core: PicoRV32 (YosysHQ, ISC license)
