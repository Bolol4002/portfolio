Fault-Tolerant ADC · Analog

QSPICEAnalog DesignMixed-Signal
GitHub

Overview

A fault-tolerant ADC block for an edge IoT device, designed in QSPICE. The design layers a fault-detection / protection stage onto a comparator-based flash ADC so it survives a bad reference voltage.

Blocks

  • Comparator — ideal subckt, 10 MΩ input resistance, Vhigh / Vlow outputs
  • 8-to-3 Priority Encoder — encodes 8 comparator outputs into a 3-bit code (standard priority logic)
  • Fault detection module — checks Vref against a safe window of 7 V – 9 V:
    • Bfault_detect — fault = (V(vin) > 7) && (V(vin) < 9) ? 0 : 1
    • Berror — outputs 1 V error flag on fault, 0 V normal
    • Bgate — passes Vref to the comparator ladder when normal, 0 V on fault
  • Filtered with a 1 kΩ / 1 pF RC

Behaviour & Deliverables

If Vref is within range the value proceeds to the resistor ladder; otherwise it is blocked and an error flag is raised. Completed as a 3-1 PBL project with teammates; images included for the comparator, priority encoder, fault module, assembled ADC, and the full fault-tolerant ADC.
