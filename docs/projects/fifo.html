Synchronous FIFO

VerilogFunctional CoverageIcarus Verilog
GitHub

Overview

RTL implementation of a FIFO (First-In, First-Out) queue — from the ZipCPU blog "Getting the Basic FIFO Right" — used wherever producer speed ≠ consumer speed to absorb timing differences and prevent stalls (CPU interrupts, SDRAM bursts, UART buffers, streaming).

Design

  • rtl/fifo.v — 8-bit data path, 16 entries, count-based fill
  • Write / enqueue to tail, read / dequeue from head
  • Status: fill level, empty, full, overflow & underflow flags

Verification — The Coverage Mindset

Documents the jump from "does it work?" to "how do I prove I exercised all important behaviour?":

  • Code coverage vs. functional coverage, UCDB concepts
  • Coverage counters: cov_push, cov_pop, cov_full, cov_empty
  • Waveform red flags: count > DEPTH (bug), pointers moving while full (bug), wrong data order
  • Next steps documented: simultaneous rd/wr, pointer wraparound, randomized transactions, scoreboard, SV covergroups, UVM

Honest caveat in the repo: the original tutorial FIFO may mis-handle overflow/underflow; this repo is primarily educational.
